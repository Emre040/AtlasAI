**Findings**

- Cohort sizes: NK-cell lineage enriched = 65 genes; B-cell lineage enriched = 301 genes. (evidence: a3 row 0: gene=STYK1, ensembl=ENSG00000060140 | a2 row 0: gene=WNT16, ensembl=ENSG00000002745)
- NK-cell cohort mean nTPM: NK-cells = 52.46, naive B-cells = 0.28, memory B-cells = 0.28, T-regs = 0.09. (evidence: a21 row 0: mean_NK-cell=52.4631 | a22 row 0: mean_naive B-cell=0.281538 | a23 row 0: mean_memory B-cell=0.283077 | a24 row 0: mean_T-reg=0.0923077)
- B-cell cohort mean nTPM: NK-cells = 1.08, naive B-cells = 601.11, memory B-cells = 686.07, T-regs = 1.28. (evidence: a25 row 0: mean_NK-cell=1.08339 | a26 row 0: mean_naive B-cell=601.113 | a27 row 0: mean_memory B-cell=686.067 | a28 row 0: mean_T-reg=1.28306)
- The B-cell lineage enriched cohort contains 7 true CD markers: CD19, CD20, CD22, CD72, CD79A, CD79B, CD81, CD200. (evidence: a12 row 0: gene=CD79B, ensembl=ENSG00000007312; row 1: gene=CD22, ensembl=ENSG00000012124; row 2: gene=CD200, ensembl=ENSG00000091972; row 3: gene=CD79A, ensembl=ENSG00000105369; row 4: gene=CD81, ensembl=ENSG00000110651; row 5: gene=CD72, ensembl=ENSG00000137101; row 6: gene=CD19, ensembl=ENSG00000177455)
- The NK-cell lineage enriched cohort contains no true CD markers. The single gene with 'CD' in its name is CDHR1 (Cadherin Related Family Member 1), which is a cadherin, not a Cluster of Differentiation marker. (evidence: a8 row 0: gene=CDHR1, ensembl=ENSG00000148600)
- The two cohorts share 0 genes. The hypergeometric test against the universe of 2,197 all lineage enriched genes gives an expected overlap of 8.91, observed 0, fold = 0, p = 1 (no significant depletion). (evidence: a4 row 0: a=301, b=65, shared=0, universe=2197, expected=8.91, fold=0, odds_ratio=0, p_value=1, test=hypergeometric, one-sided (over-representation))

**Limitations**

- The lineage-enriched classification used here is the RNA-based 'Immune cell lineage category (RNA)' field, not the protein-level 'Lineage Enriched' protein class. The two can differ; this study reports the RNA-based annotation.
- CD marker identification was based on gene symbol inspection (contains 'CD') and manual exclusion of non-CD genes (AICDA, PCDHGA12, CDHR1). A formal CD nomenclature database cross-reference was not performed.
- Mean nTPM values are arithmetic means across all genes in each cohort; they are sensitive to the few very highly expressed genes and do not represent a typical gene's expression.
