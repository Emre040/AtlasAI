Give each size and, for each cohort, the mean nTPM in NK-cells, naive B-cells, memory B-cells and T-regs. Draw a heatmap of the ten highest-expressed genes of each cohort across all immune cell types on a log scale. Which members are CD markers? Test the two cohorts for overlap using all lineage enriched genes as the universe. Provide the table.

Based on the tools available to query the Human Protein Atlas, **this analysis cannot be performed**. 

Here is an explanation of the specific data and tool limitations:

---

### 1. Inability to Identify Cohorts Lineage Enriched in NK-Cells Alone or B-Cells Alone
* **No blood lineage filtering capability**: The search tools (`search_proteins` and `advanced_search`) only support text queries and filters for chromosome, subcellular location, normal tissue specificity, protein classes, cancer prognostics, and antibody reliability. They do not support querying or filtering by **RNA blood lineage specificity** or specific blood cell lineages (e.g., queries for `"Lineage enriched"` or blood lineage fields return empty or text-matched results rather than structured cohort lists).
* **Genome-wide identification**: Identifying all genes lineage-enriched specifically in NK-cells or B-cells alone requires querying the entire genome (~20,000 protein-coding genes), which cannot be enumerated or filtered by blood lineage specificity using the current toolset. Consequently, the exact cohort sizes cannot be determined.

---

### 2. Missing Blood Cell Types in Expression Tools
* **Incomplete blood expression profiles**: The dedicated tool `get_blood_expression` only returns nTPM values for **5 blood cell types**:
  * Basophil
  * Classical monocyte
  * Eosinophil
  * Neutrophil
  * NK-cell
* **Missing cell types**: Expression data for **naive B-cells**, **memory B-cells**, **T-regs**, and other lymphoid subsets (CD4/CD8 naive/memory T-cells, MAIT cells, dendritic cells, etc.) are **not provided** by `get_blood_expression`.
* While `get_protein_by_ensembl` provides `RNA blood cell specific nTPM`, it only reports values for cell types where a gene is specifically enriched/detected, rather than complete expression values across all immune cell types for every gene. Thus, the cohort mean nTPM values for naive B-cells, memory B-cells, and T-regs cannot be computed.

---

### 3. Heatmap Across All Immune Cell Types & CD Marker Identification
* Because the comprehensive cohorts cannot be extracted to identify the true top 10 highest-expressed genes for each lineage, and because full nTPM profiles across the complete panel of 18 blood immune cell types are absent from the tool responses, the 10-gene heatmap cannot be plotted from tool data.
* While CD marker status can be verified for individual known genes via `get_protein_info` / `get_protein_classes`, determining which genes constitute the top 10 highest-expressed members of each cohort is precluded by the lack of complete cohort expression rankings.

---

### 4. Overlap Test and Contingency Table
* Testing the two cohorts for overlap (and building the $2 \times 2$ contingency table against the universe of all lineage-enriched blood genes) requires:
  1. The total count of all lineage-enriched genes across all blood lineages.
  2. The exact size and members of the NK-cell lineage-enriched cohort.
  3. The exact size and members of the B-cell lineage-enriched cohort.
* By definition in the HPA classification, lineage enrichment in a single lineage alone precludes membership in another mutually exclusive lineage alone (overlap count is expected to be 0), but the exact cohort sizes and total universe count required for Fisher's exact test cannot be retrieved using the available API functions.
