### 5. Why the consensus is not an independent third replication cohort

1. **It is a derived, not measured, quantity.** The consensus nTPM for a gene×tissue is computed *from* the very HPA and GTEx nTPM values (pooled/normalized across the combined sample sets). When both source values exist, the consensus value is a deterministic function of them; it contains no information either source lacks.
2. **Double counting / inflated sample size.** Treating it as a third "replicate cohort" counts the same physical RNA-seq measurements (99 HPA samples + the GTEx samples) twice — once inside each source and again inside the combined consensus. Apparent three-way agreement can arise purely from the arithmetic; effective coverage does not triple, and per-gene differences are not independent observations.
3. **Bias induced by the combination rule.** Because the consensus re-weights (pools) the two sources, it systematically sits *between* them on the log2 scale; its correlation with each source is mechanically high, which would mask rather than reveal genuine HPA-vs-GTEx discordance. A true replication cohort (independent samples, lab, normalization) would not share this dependency.
Hence, per your specification, the consensus file is used only as annotation (consensus nTPM + specificity label for the selected genes) and never as a substitute for either source in any statistic or ranking — exactly as the tables above reflect, with every cross-source figure reported as N/A whenever it depends on GTEx values that the available tools cannot supply.
