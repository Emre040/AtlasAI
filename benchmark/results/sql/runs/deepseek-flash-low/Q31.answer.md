## 5. Why the consensus file is **not** an independent third replication cohort

The consensus (`rna_tissue_consensus.nTPM`) is **constructed from** the same two sources it would supposedly validate. Numerically, across the 1,483 eligible TFs per tissue, every consensus value equals one (or both) of the two source values — the number of genes differing from *both* sources is exactly **0**:

| Tissue | n | consensus = GTEx (within 0.05) | consensus = HPA (within 0.05) | consensus = neither |
|---|---|---|---|---|
| colon | 1483 | 1076 | 640 | **0** |
| ovary | 1483 | 870 | 905 | **0** |
| testis | 1483 | 828 | 779 | **0** |

This is visible directly in the discrepancy tables above: in essentially every colon/testis row the consensus nTPM is *identical* to the GTEx nTPM (e.g. colon ATF4 → 826.1 = GTEx), and in ovary it frequently equals the HPA nTPM (e.g. ovary EGR1 → 729.2 = HPA). A replication cohort must provide a genuinely independent measurement of the same quantity; the consensus is instead a **derived aggregate** that, for any given gene/tissue, simply reproduces the HPA or the GTEx number (or a value between them). Correlating HPA (or GTEx) against consensus therefore returns agreement by construction, **not** an independent test of reproducibility. The only honest two‑cohort reproducibility test is the one performed here — HPA nTPM vs GTEx nTPM directly.

The consensus file cannot serve as a third cohort because it is arithmetically the same data.
