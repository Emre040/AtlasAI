## Five‑year survival‑benefit calculation

**Important caveat:** the HPA tables contain only *qualitative* prognostic calls plus p‑values — there are **no hazard ratios or survival endpoints** anywhere in these files. An *absolute* "percentage‑point improvement in 5‑year survival" therefore **cannot be derived** from the tools. What *can* be derived is a **relative benefit proxy**: inhibition helps only if a gene is (a) over‑expressed in tumour (CPTAC logFC) **and** (b) significantly associated with worse survival (prognostic p). I therefore use

$$B = \text{logFC}_{\text{CPTAC}} \times (-\log_{10} p_{\text{prog}})$$

and normalise to % of the maximum.

| Gene | logFC | −log₁₀ p_prog | Benefit score B | Benefit (% of max) |
|---|---|---|---|---|
| **CCNA2** | 1.98289 | 5.2862 | **10.4819** | **100.0** |
| ERO1A | 1.19298 | 7.9126 | 9.4395 | 90.1 |
| GTSE1 | 1.25023 | 5.3170 | 6.6475 | 63.4 |
| ALG3 | 1.12989 | 4.3953 | 4.9663 | 47.4 |
| PLOD2 | 1.14465 | 3.5328 | 4.0439 | 38.6 |

**Best treatment target: CCNA2** (highest score; the result is robust — CCNA2 also ranks first if significance is instead measured by the normal quantile z of the prognostic p‑value: 1.98289×4.57 = 9.06 vs ERO1A 1.19298×5.62 = 6.71). ERO1A is a close second. **Caveat:** neither is an FDA‑approved drug target, and neither is a blood‑secreted protein, so among this intersection there is no approved‑drug or blood‑biomarker option at all.

### Matplotlib code (reproduces both charts with the tables above)

```python
import matplotlib.pyplot as plt

genes   = ["CCNA2","GTSE1","ERO1A","PLOD2","ALG3"]
logfc   = [1.98289, 1.25023, 1.19298, 1.14465, 1.12989]
prog_p  = [5.174e-6, 4.819e-6, 1.223e-8, 2.932e-4, 4.024e-5]
import math
neglogp = [-math.log10(p) for p in prog_p]
benefit = [round(100*l*(-math.log10(p)) /
            max(1.98289*-math.log10(5.174e-6),
                1.25023*-math.log10(4.819e-6),
                1.19298*-math.log10(1.223e-8),
                1.14465*-math.log10(2.932e-4),
                1.12989*-math.log10(4.024e-5)),1)
           for l,p in zip(logfc,prog_p)]

# Scatter
plt.figure()
plt.scatter(logfc, neglogp)
for g,x,y in zip(genes,logfc,neglogp): plt.annotate(g,(x,y))
plt.xlabel("CPTAC logFC (Lung AC)"); plt.ylabel("-log10 prognostic p (LUAD TCGA)")
plt.title("Protein / prognostic association"); plt.show()

# Bar chart
plt.figure()
order = sorted(range(len(genes)), key=lambda i:-benefit[i])
plt.bar([genes[i] for i in order],[benefit[i] for i in order])
plt.ylabel("Predicted survival benefit (% of max)")
plt.title("Predicted survival-benefit by target"); plt.show()
```
