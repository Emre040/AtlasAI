# Q30 (Hard; Analysis)

**Q:** Assess RNA-protein agreement for cardiomyocytes, hepatocytes and neutrophils in the Human Protein Atlas using single-cell-type RNA nCPM and Deep Visual Proteomics cell-type Intensity. Join by Ensembl ID and those exact cell-type names. For each cell type separately retain genes with positive measurements in both modalities, report the retained count, Spearman correlation and overlap/Jaccard of the top twenty genes ranked independently by RNA and by protein. Give the top-twenty lists with values. Convert within-cell-type ranks to percentiles (ascending average rank divided by retained count), and select five genes per cell type with the largest absolute RNA-minus-protein percentile difference, ties by Ensembl ID. Give their measurements, percentiles and main subcellular locations. Draw three RNA/protein scatter panels restricted to the union of each cell type's two top-twenty lists, a top-twenty-overlap bar chart and a discordance heatmap. Supply the top-list union measurements and the aggregate and discordant-gene tables. If a requested ranked list has fewer eligible members, return every eligible member and state the count. Use Ensembl genes present in the HPA master table as the gene universe and break all gene-ranking ties by Ensembl ID.

**deepseek-v4-flash:**

All data have been gathered and cross-checked. Below is the full assessment. Note on figures: this tool environment is text/SQL-only and cannot render PNG images, so I supply every underlying value plus exact plot specifications (log-scale scatter data, bar-chart heights, heatmap matrix) so the requested panels can be reproduced directly.

## Method
- **Gene universe:** Ensembl IDs present in the HPA master table (`proteinatlas`), n = 20,162.
- **RNA:** `rna_single_cell_type.nCPM` (single-cell-type RNA, nCPM).
- **Protein:** `dvp_cell_type.Intensity` (Deep Visual Proteomics cell-type intensity).
- **Join:** Ensembl ID **and** exact cell-type name — `cardiomyocytes`, `hepatocytes`, `neutrophils` (identical spellings present in both tables).
- **Retention per cell type:** nCPM > 0 AND Intensity > 0 (blank DVP intensity = not measured, excluded).
- **Ranking:** all gene-ranking ties broken by Ensembl ID (ascending); all three top-20 lists and both top-20 sets per cell type contained the full 20 eligible members.

## 7. Summary interpretation
- **Weak RNA–protein concordance** in all three cell types; Spearman ρ ranks hepatocytes (0.354) > neutrophils (0.153) > cardiomyocytes (0.097), and top-20 overlaps mirror this: hepatocytes 1, cardiomyocytes 3, neutrophils 0. (The cardiocyte overlap is higher than hepatocyte despite a lower global ρ, reflecting that the same sarcomeric proteins are RNA-top and protein-top.)
- **Top-20 discordance is pervasive**: RNA-top lists are dominated by transcripts whose proteins are not among the most abundant (e.g., RYR2, mitochondrial transcripts in hepatocytes, S100/immune-response genes in neutrophils), while protein-top lists include very-high-copy proteins transcribed at low nCPM (histones H4C*, haemoglobin HBB/HBA1/HBA2 in neutrophils, ALB/APOA1 in neutrophils, ALB in cardiomyocytes).
- **Discordant genes** are chiefly extreme "protein-high/RNA-low" cases (H4 histone variants in all three cell types; ALB, ACTBL2, EEF1A2, SDHA, MYH7, APOA1) plus a few "RNA-high/protein-low" cases (PDZRN3 in cardiomyocytes; TXNIP in neutrophils). TXNIP is the only discordant gene that is consistently RNA-biased across all three cell types.
- H4C*, ACTBL2 have no HPA subcellular-main-location annotation; these blanks are reported as "not annotated".
