## Caveats / notes
- "Share secreted to blood" was computed using the HPA `Secretome location = "Secreted to blood"` annotation. Cross-checking with the `Blood concentration` columns shows measured blood presence for some genes annotated otherwise (e.g., SCGB1A1, SFTPB, SFTPD, NAPSA have MS blood concentrations but are annotated "Secreted in other tissues"; ACTA1, CA3, MYH1, ACTN3 have plasma/IM concentrations yet are not in the secretome-to-blood annotation). I used the explicit `Secretome location` annotation as the operational definition since it is the only field that directly labels "Secreted to blood".
- Subcellular main location is empty in the master table for several secreted surfactant/secretoglobin proteins (SFTPA/B/C/D, SCGB1A1, SCGB3A2, NAPSA); those are reported as "none reported", which is what the source contains.
