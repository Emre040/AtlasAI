### 6. Why the Consensus File is Not an Independent Third Replication Cohort

The `rna_tissue_consensus` file in the Human Protein Atlas cannot serve as an independent third replication cohort because:
1. **Mathematical Derivative, Not Biological Replicate:** The consensus dataset contains no new biological donors, sequencing libraries, or experimental measurements. 
2. **Deterministic Aggregation Function:** Consensus $n\text{TPM}$ values are generated directly as a function of the underlying input sources (HPA, GTEx, and FANTOM5). In the HPA pipeline, consensus tissue $n\text{TPM}$ is defined as the maximum normalized value across the input datasets ($\text{consensus } n\text{TPM} = \max(\text{HPA } n\text{TPM}, \text{GTEx } n\text{TPM})$) to ensure that transcript detection in any single validated platform is preserved in the summary atlas.
3. **Statistical Circularity:** Because the consensus values are derived from HPA and GTEx, treating consensus as an independent third cohort creates circular confirmation bias, inflating concordances and masking platform-specific artifacts (such as post-mortem ischemia in GTEx or surgical tissue resection artifacts in HPA). True external replication requires an entirely independent cohort processed with distinct sample acquisition and library preparation workflows.
