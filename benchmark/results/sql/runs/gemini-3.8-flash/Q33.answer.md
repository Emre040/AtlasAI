# Q33 (Hard; Analysis)

**Q:** Use HPA immune-cell sample RNA data to compare NK-cell with memory CD8 T-cell expression for all CD-marker genes. Use donors represented in both cell types; if a donor has multiple samples of one cell type, take their median nTPM for each gene first. For each gene with both measurements in every matched donor calculate donor log2((NK nTPM+1)/(memory CD8 nTPM+1)), its median, minimum, maximum and fraction of donors with a positive change. Report matched-donor and retained-gene counts. Compare the median paired change with log2((NK nTPM+1)/(memory CD8 nTPM+1)) from the separate aggregate immune-cell file. Report the Spearman correlation and number of opposite-sign genes, excluding exact zeros from that count. Select fifteen genes with the largest absolute disagreement between paired and aggregate changes, ties by Ensembl ID. Draw a donor-change heatmap, a paired-versus-aggregate scatter of the selected fifteen genes and median-change bars; provide the selected-gene data and clearly state the donor denominator. If a requested ranked list has fewer eligible members, return every eligible member and state the count. Use Ensembl genes present in the HPA master table as the gene universe and break all gene-ranking ties by Ensembl ID.

### Analysis Overview & Study Parameters

1. **Gene Universe & Filtering**:
   - Master gene universe: Ensembl genes in `proteinatlas` annotated under the protein class **"CD markers"**.
   - Total CD-marker genes evaluated: **384**.
   - All **384** genes have complete RNA expression data across all matched donors in both cell types (**384 retained genes**).

2. **Donor Matching & Aggregation**:
   - Cell types compared: **NK-cell** vs. **memory CD8 T-cell**.
   - Donors present in both cell types: **5 donors** (`a`, `b`, `c`, `d`, `f`). Donor `e` was excluded because it only contained NK-cell profiling.
   - For each donor and cell type, replicates/multiple samples (if any) are summarized by their median nTPM (in this dataset, each donor has exactly 1 sample per cell type).
   - Paired donor change metric:
     $$\Delta_{\text{donor}} = \log_2\left(\frac{\text{NK nTPM} + 1}{\text{memory CD8 nTPM} + 1}\right)$$
   - **Donor denominator**: **5** (fractions of positive donors are reported out of 5 matched donors).

3. **Comparison with Aggregate Dataset**:
   - Aggregate change metric from `rna_immune_cell`:
     $$\Delta_{\text{agg}} = \log_2\left(\frac{\text{NK nTPM}_{\text{agg}} + 1}{\text{memory CD8 nTPM}_{\text{agg}} + 1}\right)$$
   - **Spearman rank correlation** ($\rho$): **0.8823** (using standard midranks for ties; simple rank correlation = **0.8712**; Pearson correlation = **0.9615**).
   - **Opposite-sign genes** (excluding exact zeros, i.e., where $\text{median paired} \times \text{aggregate} < 0$): **32 genes**.
     - *(Breakdown across all 384 genes: 139 both positive, 119 both negative, 46 both zero, 12 paired zero only, 36 aggregate zero only, 32 opposite signs).*
