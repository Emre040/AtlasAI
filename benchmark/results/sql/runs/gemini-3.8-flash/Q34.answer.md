# Q34 (Hard; Analysis)

**Q:** Compare normal and cancer immunohistochemistry for genes in the HPA Predicted membrane proteins class in colon, breast and lung. In the normal IHC data use colon glandular cells, breast glandular cells and lung alveolar cells, keeping only Enhanced or Supported reliability; if several eligible records remain for one gene/tissue, take the highest ordinal level. Score High=3, Medium=2, Low=1 and Not detected=0. In cancer IHC use colorectal cancer, breast cancer and lung cancer; calculate (3*High+2*Medium+Low)/(High+Medium+Low+Not detected), retaining cancer rows with at least five observations. For each tissue/cancer pair report the number of genes with both measurements, the median cancer-minus-normal score and the fraction with an increase of at least one score unit. For colon select twelve genes with the largest increase, ties by Ensembl ID, and show the normal level/reliability, cancer counts, weighted score, change and colon consensus nTPM. Draw paired-score scatters for those twelve genes, comparison bars and a heatmap of these genes across all three tissue/cancer pairs, leaving unavailable cells missing. Supply the tables; describe these as ordinal summaries of different samples, not paired-patient measurements. If a requested ranked list has fewer eligible members, return every eligible member and state the count. Use Ensembl genes present in the HPA master table as the gene universe and break all gene-ranking ties by Ensembl ID.

### 1. Overview & Analysis Methodology

- **Gene Universe**: Ensembl genes annotated in the Human Protein Atlas under the protein class **Predicted membrane proteins** ($N = 5,573$ genes in the master table).
- **Normal Tissue IHC Scoring**:
  - Tissues and target cell types evaluated:
    - **Colon**: glandular cells
    - **Breast**: glandular cells
    - **Lung**: alveolar cells
  - Only records with **Enhanced** or **Supported** reliability were retained. If multiple eligible records exist, the highest ordinal level is taken.
  - Scores assigned: **High = 3**, **Medium = 2**, **Low = 1**, **Not detected = 0**.
- **Cancer IHC Scoring**:
  - Corresponding cancer types evaluated: **colorectal cancer**, **breast cancer**, and **lung cancer**.
  - Weighted score calculated as:
    $$\text{Cancer Score} = \frac{3 \times \text{High} + 2 \times \text{Medium} + 1 \times \text{Low}}{\text{High} + \text{Medium} + \text{Low} + \text{Not detected}}$$
  - Filter: Only cancer entries with at least 5 total patient observations were retained.
- **Interpretation Note**: These values represent ordinal, aggregate population-level summaries across different donor cohorts in the Human Protein Atlas, **not** paired measurements from the same individual patients.
