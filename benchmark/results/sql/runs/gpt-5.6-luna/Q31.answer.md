## Why consensus is not a third independent replication cohort

The consensus nTPM is an HPA-derived integrated/consensus representation rather than an independently sampled cohort. It is therefore not statistically independent of the HPA and GTEx source measurements. In this dataset, the consensus values for the discrepancy genes equal the GTEx values, illustrating that consensus can inherit or select source values rather than provide a new biological replicate. Consequently, treating HPA, GTEx, and consensus as three independent cohorts would artificially inflate the apparent replication evidence.
