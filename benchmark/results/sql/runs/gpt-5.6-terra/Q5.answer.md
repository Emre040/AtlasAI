import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

    "Other": "#c7c7c7",
    "Pancreas-enhanced enzyme": "#d62728",

## Table behind the figure

The following query returns the complete point table—**20,162 rows**—with gene symbol, Ensembl ID, pancreas and kidney consensus nTPM, and plotting cohort. The tool can return at most 2,000 rows in one response, so I cannot inline the full 20,162-row table here; this is the exact table-generating query.

```sql
WITH g AS (
  SELECT
    Gene AS gene_symbol,
    Ensembl AS ensembl_id,
    "Protein class" AS protein_class,
    "RNA tissue specificity" AS rna_tissue_specificity,
    "RNA tissue specific nTPM" AS tissue_specific_ntpm
  FROM proteinatlas
),
points AS (
  SELECT
    g.*,
    MAX(
      CASE WHEN r.Tissue = 'pancreas'
      THEN TRY_CAST(r.nTPM AS DOUBLE) END
    ) AS pancreas_nTPM,
    MAX(
      CASE WHEN r.Tissue = 'kidney'
      THEN TRY_CAST(r.nTPM AS DOUBLE) END
    ) AS kidney_nTPM
  FROM g
  JOIN rna_tissue_consensus r
    ON g.ensembl_id = r.Gene
  GROUP BY ALL
)
SELECT
  gene_symbol,
  ensembl_id,
  pancreas_nTPM,
  kidney_nTPM,
  CASE
    WHEN protein_class ILIKE '%Enzymes%'
      AND rna_tissue_specificity = 'Tissue enhanced'
      AND regexp_matches(tissue_specific_ntpm, '(^|;)pancreas:')
      THEN 'Pancreas-enhanced enzyme'
    WHEN protein_class ILIKE '%Transporters%'
      AND rna_tissue_specificity = 'Tissue enriched'
      AND regexp_matches(tissue_specific_ntpm, '(^|;)kidney:')
      THEN 'Kidney-enriched transporter'
    ELSE 'Other'
  END AS cohort
FROM points
ORDER BY cohort, gene_symbol;
```
