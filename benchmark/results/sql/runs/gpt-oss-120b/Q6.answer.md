**3. Fraction of partners whose main location includes the nucleus**

The query  

```sql
SELECT COUNT(*) AS total,
       SUM(CASE WHEN "Subcellular main location" LIKE '%Nucle%' THEN 1 ELSE 0 END) AS with_nucleus
FROM proteinatlas
WHERE Ensembl IN (SELECT DISTINCT CASE WHEN ensembl_gene_id_1='ENSG00000141510' THEN ensembl_gene_id_2 ELSE ensembl_gene_id_1 END
                  FROM interaction_consensus
                  WHERE ensembl_gene_id_1='ENSG00000141510' OR ensembl_gene_id_2='ENSG00000141510');
```

returned `total = 123` and `with_nucleus = 86`.  

**Fraction = 86 / 123 ≈ 0.699 (≈ 70 %).**
