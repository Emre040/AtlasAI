**Findings**

- Eligible transcription-factor genes (finite nonnegative nTPM in both HPA and GTEx) number 1,483 in each of colon, ovary, and testis. (evidence: a18 row 0: count=1483 | a21 row 0: count=1483 | a24 row 0: count=1483)
- Spearman correlation between HPA and GTEx nTPM: colon r = 0.9117, ovary r = 0.948, testis r = 0.915 (n = 1,483, p = 0 for all three tissues). Ovary shows the strongest rank agreement. (evidence: a19 row 0: r=0.9117, n=1483, p_value=0 | a22 row 0: r=0.948, n=1483, p_value=0 | a25 row 0: r=0.915, n=1483, p_value=0)
- Median absolute log2((HPA+1)/(GTEx+1)): colon 0.371969, ovary 0.275634, testis 0.321928. Ovary shows the smallest median discrepancy between the two sources. (evidence: a20 row 0: median_abs_log2_colon=0.371969 | a23 row 0: median_abs_log2_ovary=0.275634 | a26 row 0: median_abs_log2_testis=0.321928)
- Top-20 list overlap: colon 11 of 29 (Jaccard = 0.37931), ovary 14 of 26 (Jaccard = 0.538462), testis 12 of 28 (Jaccard = 0.428571). Ovary has the highest Jaccard index, indicating the greatest concordance between the two sources' top-ranked TFs. (evidence: a84 row 0: jaccard=0.37931, union=29, count=11, tissue=colon; row 1: jaccard=0.538462, union=26, count=14, tissue=ovary; row 2: jaccard=0.428571, union=28, count=12, tissue=testis)
- The largest |log2 ratio| in colon is HIF3A (|log2| = 4.0634, HPA nTPM = 2.2, GTEx nTPM = 52.5, consensus = 52.5). In ovary, NFKBIL1 leads (|log2| = 3.43382, HPA = 2.1, GTEx = 32.5, consensus = 32.5). In testis, NFKBIL1 also leads (|log2| = 3.49985, HPA = 0.6, GTEx = 17.1, consensus = 17.1). (evidence: a48 row 0: gene=HIF3A, consensus_colon=52.5, hpa_colon=2.2, gtex_colon=52.5, abs_log2_colon=4.0634 | a49 row 0: gene=NFKBIL1, consensus_ovary=32.5, hpa_ovary=2.1, gtex_ovary=32.5, abs_log2_ovary=3.43382 | a50 row 0: gene=NFKBIL1, consensus_testis=17.1, hpa_testis=0.6, gtex_testis=17.1, abs_log2_testis=3.49985)
- The HPA consensus nTPM is not an independent third replication cohort. The consensus file is a deterministic aggregation of the HPA and GTEx measurements, so it carries no independent information beyond what the two sources already provide. In the top-10 discrepancy tables, the consensus value equals the GTEx value in the leading cases (HIF3A colon: consensus = 52.5 = GTEx; NFKBIL1 ovary: consensus = 32.5 = GTEx; NFKBIL1 testis: consensus = 17.1 = GTEx), confirming that the consensus is dominated by the GTEx measurement when HPA values are low. Using the consensus as a third replicate would therefore inflate apparent reproducibility without adding new biological information. (evidence: a48 row 0: consensus_colon=52.5, gtex_colon=52.5, hpa_colon=2.2 | a49 row 0: consensus_ovary=32.5, gtex_ovary=32.5, hpa_ovary=2.1 | a50 row 0: consensus_testis=17.1, gtex_testis=17.1, hpa_testis=0.6)

**Limitations**

- The consensus nTPM is a deterministic function of the HPA and GTEx values; it cannot serve as an independent replication and its agreement with either source is circular by construction.
- The gene universe is restricted to the 1,485 TF Ensembl genes present in the HPA master table; TFs absent from HPA are excluded from all analyses.
- Spearman correlation measures rank agreement only; the median |log2 ratio| captures typical magnitude of absolute discrepancy but does not characterise the full distribution.
- Two of the 1,485 TF genes had no GTEx row in at least one tissue and were excluded from eligibility, reducing the eligible set to 1,483 per tissue.
