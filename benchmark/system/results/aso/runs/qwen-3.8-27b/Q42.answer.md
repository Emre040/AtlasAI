**Limitations**

- The HPA release does not provide a consensus nTPM column for TCGA cancer types. The RNA expression heatmap and the kirc_median_pTPM / luad_median_pTPM columns in the ranked table use the median of per-sample pTPM values (per-cancer-type median TPM) from rna_cancer_sample.tsv, which is a different normalization from nTPM (per-tissue median TPM). True consensus nTPM for KIRC and LUAD is not identified by this data.
- The 'evidence' column in the ranked table records which KIRC category (potential or validated favourable) each gene belongs to; 'evidence_2' records the corresponding LUAD category. A gene may appear in both potential and validated categories in the same cancer; the table shows the category from which the best p-value was drawn.
- The scatter plot (a79) uses the minimum p-value across all four prognostic categories per gene per cancer, not the favourable-only p-value; it is intended to show the overall prognostic strength landscape rather than the favourable-direction ranking.
