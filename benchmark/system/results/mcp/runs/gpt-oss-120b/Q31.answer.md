### Why the consensus file is **not** an independent third replication cohort

Even if the consensus nTPM values were obtainable, they would still **not constitute an independent replication** because:

1. **Consensus is a composite** – it is calculated by averaging (or otherwise combining) the HPA nTPM, GTEx nTPM, and sometimes additional RNA‑seq datasets. Consequently, the consensus inherits information from both HPA and GTEx.
2. **Statistical dependence** – because the consensus includes the very measurements we are comparing, any correlation between a source (HPA or GTEx) and the consensus is inflated; the consensus is not an external validation set but a weighted blend of the same data.
3. **Non‑independent errors** – systematic biases present in HPA (e.g., library preparation, batch effects) or in GTEx will partially propagate into the consensus, so discrepancies cannot be attributed solely to one source.

For a truly independent replication, a **fourth, completely separate dataset** (e.g., an independent RNA‑seq study not used in the consensus construction) would be required.
