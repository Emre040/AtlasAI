## Overlap and hypergeometric test

- Overlap between cohorts = **0 genes** (also 0 Ensembl IDs).
- Atlas background (total genes in `proteinatlas`) = **20,162 rows** (~20,151 unique symbols).
- Hypergeometric parameters: N = 20,162; K (cohort A) = 36; n (cohort B) = 29; observed overlap k = 0.
- Expected overlap by chance = K·n/N = 36×29/20,162 ≈ **0.052 genes**.
