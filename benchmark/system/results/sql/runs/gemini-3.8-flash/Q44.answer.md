### 3. Absolute Molecules per Cell and Protein-to-RNA Ratio Determination

> **Note on Absolute Calibration**:  
> True absolute copy numbers (molecules per cell) cannot be determined directly with the tools available in the Human Protein Atlas database. In HPA, mass spectrometry data are reported as label-free MS **Intensity** (arbitrary units, $\text{a.u.}$), and RNA expression is reported as **nTPM** (normalized transcripts per million). Converting these relative quantities into absolute molecules per cell requires external calibration anchors (e.g., total cellular mRNA molecules per cell $\sim 200{,}000\text{–}500{,}000$, and a proteomic ruler / histone-based total cellular protein calibration), which are not part of the HPA database.
>
> Using the available measurements directly:
> - **Normal Protein Abundance**: MS Intensity ($\text{a.u.}$)
> - **Tumour Protein Abundance**: $\text{Normal MS Intensity} \times 2^{\text{CPTAC }\log_2\text{FC}}$ ($\text{a.u.}$)
> - **Normal Protein-to-RNA Ratio**: $\frac{\text{Normal MS Intensity}}{\text{Lung RNA nTPM}}$ ($\text{a.u.}/\text{nTPM}$)
> - **Tumour Protein-to-RNA Ratio**: $\frac{\text{Tumour Protein Abundance}}{\text{Lung RNA nTPM}}$ ($\text{a.u.}/\text{nTPM}$)
