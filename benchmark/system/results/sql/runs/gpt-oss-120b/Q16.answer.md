### How the numbers were obtained  

* **Selection of the 10 genes** – query:

```sql
SELECT pa.Gene, pa.Ensembl, tc.nTPM
FROM   proteinatlas pa
JOIN   rna_tissue_consensus tc
       ON pa.Ensembl = tc.Gene
WHERE  pa."RNA tissue specificity" = 'Tissue enriched'
  AND  tc.Tissue = 'Liver'
ORDER BY CAST(tc.nTPM AS DOUBLE) DESC
LIMIT 10;
```

* **Interaction partner counts** – query:

```sql
SELECT ensembl_gene_id_1 AS seed, COUNT(DISTINCT ensembl_gene_id_2) AS partner_count
FROM   interaction_consensus
WHERE  ensembl_gene_id_1 IN (list of the 10 Ensembl IDs)
GROUP  BY ensembl_gene_id_1;
```

* **Sub‑cellular location distribution** – query:

```sql
SELECT ic.ensembl_gene_id_1   AS seed,
       pa."Subcellular main location" AS location,
       COUNT(*) AS cnt
FROM   interaction_consensus ic
JOIN   proteinatlas pa
       ON ic.ensembl_gene_id_2 = pa.Ensembl
WHERE  ic.ensembl_gene_id_1 IN (list of the 10 IDs)
GROUP  BY ic.ensembl_gene_id_1, pa."Subcellular main location";
```

* **Partner liver nTPM values (for the scatter plot)** – query:

```sql
SELECT ic.ensembl_gene_id_1 AS seed,
       ic.ensembl_gene_id_2 AS partner,
       tc_seed.nTPM      AS seed_nTPM,
       tc_partner.nTPM   AS partner_nTPM
FROM   interaction_consensus ic
JOIN   rna_tissue_consensus tc_seed
       ON ic.ensembl_gene_id_1 = tc_seed.Gene
      AND tc_seed.Tissue = 'Liver'
JOIN   rna_tissue_consensus tc_partner
       ON ic.ensembl_gene_id_2 = tc_partner.Gene
      AND tc_partner.Tissue = 'Liver'
WHERE  ic.ensembl_gene_id_1 IN (list of the 10 IDs);
```

* **Secreted‑to‑blood partners** – query:

```sql
SELECT ic.ensembl_gene_id_1 AS seed,
       ic.ensembl_gene_id_2 AS partner,
       pa."Secretome location"
FROM   interaction_consensus ic
JOIN   proteinatlas pa
       ON ic.ensembl_gene_id_2 = pa.Ensembl
WHERE  ic.ensembl_gene_id_1 IN (list of the 10 IDs)
  AND  pa."Secretome location" = 'Blood';
```
