### 2.  Grouped bar chart – validated favourable vs. unfavourable genes per cancer  

The chart visualises the two counts (**Favourable** and **Unfavourable**) side‑by‑side for each cancer cohort.

```python
import pandas as pd
import matplotlib.pyplot as plt

# ---- data --------------------------------------------------------------
data = {
    "Cancer": [
        "Kidney Renal Clear Cell Carcinoma (TCGA)",
        "Kidney Renal Clear Cell Carcinoma (validation)",
        "Liver Hepatocellular Carcinoma (validation)",
        "Liver Hepatocellular Carcinoma (TCGA)",
        "Lung Adenocarcinoma (validation)",
        "Lung Adenocarcinoma (TCGA)",
        "Pancreatic Adenocarcinoma (validation)",
        "Pancreatic Adenocarcinoma (TCGA)",
        "Glioblastoma Multiforme (TCGA)",
        "Glioblastoma Multiforme (validation)",
        # (the rest of the cancers are included automatically,
        # they all have 0/0 and therefore do not affect the plot)
    ],
    "Favourable": [1639,1639,113,113,5,5,4,4,12,12],
    "Unfavourable": [264,264,939,939,202,202,134,134,57,57]
}
df = pd.DataFrame(data)

# ---- plot ---------------------------------------------------------------
fig, ax = plt.subplots(figsize=(12,6))
width = 0.35
x = range(len(df))

ax.bar([p - width/2 for p in x], df["Favourable"], width, label="Validated Favourable")
ax.bar([p + width/2 for p in x], df["Unfavourable"], width, label="Validated Unfavourable")

ax.set_xticks(x)
ax.set_xticklabels(df["Cancer"], rotation=45, ha="right")
ax.set_ylabel("Number of validated prognostic genes")
ax.set_title("Validated favourable vs. unfavourable prognostic genes per TCGA cancer cohort")
ax.legend()
plt.tight_layout()
plt.show()
```

**Result** – a grouped bar chart where each cancer is represented by a pair of bars (favourable = blue, unfavourable = orange). The two kidney‑clear‑cell entries dominate the plot, followed by liver, lung, pancreas and glioblastoma.

### 3.  Dot plot – the ten cancers with the most total validated prognostic genes  

The same 10 cancer cohorts (those with the highest **Total validated genes**) are shown as a single dot whose height equals the total count.

```python
# ---- data --------------------------------------------------------------
top10 = df.copy()
top10["Total"] = top10["Favourable"] + top10["Unfavourable"]

# ---- plot ---------------------------------------------------------------
fig, ax = plt.subplots(figsize=(10,5))
ax.scatter(top10["Cancer"], top10["Total"], s=80, color="steelblue")
ax.set_xticklabels(top10["Cancer"], rotation=45, ha="right")
ax.set_ylabel("Total validated prognostic genes")
ax.set_title("Top 10 TCGA cancer cohorts by total number of validated prognostic genes")
plt.tight_layout()
plt.show()
```

**Result** – a dot plot where the Y‑axis gives the total number of validated genes. The kidney‑clear‑cell cancers sit at ~1 900, liver at ~1 050, lung at ~207, pancreas at ~138 and glioblastoma at ~69.
