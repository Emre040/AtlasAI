## 2.  Scatter plot – immunoassay vs. mass‑spectrometry

**What to plot**

* x‑axis : `log10_IM` (immunoassay)  
* y‑axis : `log10_MS` (mass‑spectrometry)  
* colour : `Secretome location` – here every point is coloured the same (“Secreted to blood”) because that is the only category present.  

**Python (matplotlib / seaborn) example**

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# read the table produced above
df = pd.read_csv('log10_concentrations.tsv', sep='\t')

plt.figure(figsize=(8,6))
sns.scatterplot(data=df,
                x='log10_im',
                y='log10_ms',
                hue='Secretome location',
                palette='Set2',
                edgecolor='k',
                s=60)

plt.title('Blood protein concentrations – immunoassay vs. MS (log10 scale)')
plt.xlabel('log10 Immunoassay concentration (pg/L)')
plt.ylabel('log10 Mass‑spectrometry concentration (pg/L)')
plt.legend(title='Secretome location')
plt.tight_layout()
plt.show()
```

The plot will show a tight cloud of points along the diagonal because most proteins have similar concentrations in the two assay types; a few outliers (see section 3) will lie far above or below the diagonal.

**Diverging bar chart**

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('discordant15.tsv', sep='\t')
df = df.sort_values('log10_ratio')          # order from most negative to most positive

plt.figure(figsize=(9,5))
colors = ['steelblue' if x < 0 else 'tomato' for x in df['log10_ratio']]
plt.barh(df['Gene'], df['log10_ratio'], color=colors)
plt.axvline(0, color='gray', linewidth=0.8)
plt.title('Log10( Immunoassay / Mass‑Spec ) – 15 most discordant secreted proteins')
plt.xlabel('log10 ratio')
plt.tight_layout()
plt.show()
```

The resulting bar chart will have negative bars (immunoassay < MS) on the left, positive bars (immunoassay > MS) on the right, clearly visualising the extreme outliers listed above.
