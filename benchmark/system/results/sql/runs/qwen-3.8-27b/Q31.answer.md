## 9. Why the consensus file is not an independent third replication cohort
I verified in the data: for every one of the **59,895** gene × {colon, ovary, testis} rows, `rna_tissue_consensus` nTPM equals **max(HPA nTPM, GTEx nTPM)** with zero deviation (max abs deviation 0.0; also true for the 4,449 TF rows). Therefore:
1. **Derivative, not measured:** each consensus value traces back entirely to one (or both) of the two source files — it contributes no new samples, no new measurements, no independent biological replication.
2. **Circular by construction:** because it is the deterministic element-wise maximum, any "source vs consensus" comparison is partially built in — consensus − HPA is exactly the positive part of (GTEx − HPA) and vice versa; the sign of the discrepancy and the identity of the outlier are fixed by which source was larger (visible in §6, where the consensus value always equals the larger source). It cannot independently confirm or refute a discrepancy detected in the HPA–GTEx pair.
3. **Shared gene universe:** it uses the same Ensembl gene set.
That is why this analysis used `rna_tissue_hpa` and `rna_tissue_gtex` as the two comparison sources and used the consensus file only as the requested reference annotation column (never as a stand-in for either source).
