# Q22 (documentation)

**Q:** What is the current release of the Human Protein Atlas, what new data did it add, and how many antibodies and human genes does the atlas cover in this release?

**gemini-3.8-flash:**

Based on the Human Protein Atlas release notes and news documentation:

### 1. Current Release
* The current release is **Version 25.1**, released on **May 25, 2026** (following the major **Version 25.0** release on **November 11, 2025**).  
  *(Source: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases))*

---

### 2. New Data Added in this Release
* **Version 25.1 additions:**
  * **Single Cell Resource (Deep Visual Proteomics / DVP):** Integrates cell-type resolved mass spectrometry (MS)-based protein profiles across 27 cell types representing 14 tissues (from a single healthy donor; covering almost 14,000 proteins). These profiles are matched to single-cell RNA data for side-by-side RNA–protein comparison, complete with specificity overlap and agreement scores. Classification uses 27 cell type shapes grouped into 24 cell types.  
    *(Sources: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases); [HPA News: Cell type resolution protein data based on Deep Visual Proteomics](https://www.proteinatlas.org/news/2026-05-28/hpa-integrates-cell-type-resolution-protein-data-based-on-deep-visual-proteomics))*
  * **Tissue Resource (Bulk Quantitative Proteomics):** Integrates bulk tissue MS-based quantitative proteomics profiles across 20 tissue types overlapping with the DVP samples into gene-summary pages, adding protein profiles for over 12,700 genes.  
    *(Source: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases))*

* **Version 25.0 additions (the underlying Version 25 release):**
  * **Blood Resource:** Added pan-disease plasma proteomics data across >2,500 samples (30 disease/healthy cohorts) profiled via Olink Explore HT (>5,400 proteins) and SomaScan 11K (>9,500 proteins), plus absolute quantification of >100 plasma proteins using targeted proteomics with qRePS standards.
  * **Brain Resource:** Spatial transcriptomics data updated with 3 cerebellum and 3 cerebral cortex samples using the Stereo-seq platform with tissue-layer cell type counts.
  * **Subcellular Resource:** Added subcellular localization of proteins encoded by 643 genes in human induced pluripotent stem cells (hiPSCs) and machine learning image embeddings from the SubCell model.
  * **Single Cell Resource:** Expanded to 154 cell types grouped into 53 main cell type groups across 34 tissue types, incorporating new single-nuclei and single-cell datasets (e.g., adrenal gland, pituitary gland, epididymis, urinary bladder).
  * **Structure & Interaction Resources:** Expanded AlphaFold 2-predicted structures to 83,795 isoforms for 19,904 genes (with AlphaMissense data) and AlphaFold 3-predicted structures for 22,979 consensus interactions across 7,855 genes.
  * **Tissue & Cancer Resources:** Added extended tissue profiling (8 new tissue types) and new multiplex immunohistochemistry antibody panels (notably pancreas).  
  *(Source: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases))*

---

### 3. Number of Antibodies and Human Genes Covered
* **Overall Atlas Coverage:** Version 25 covers **over 27,800 antibodies**, targeting proteins from **over 17,400 human genes** (representing ~88% of all human protein-coding genes).  
  *(Source: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases))*
* **Resource-specific breakdowns reported for this release:**
  * **Tissue section:** Protein expression profiling covers **15,312 genes** (~76% of protein-coding genes) with available antibodies.  
    *(Source: [Human Protein Atlas Introduction](https://www.proteinatlas.org/about))*
  * **Subcellular section:** Subcellular localization data covers proteins encoded by **13,603 genes** using **15,995 antibodies**.  
    *(Source: [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases))*
