**Q:** How is the consensus nTPM value of a gene in a tissue derived from the HPA and GTEx transcriptomics data?

The consensus nTPM value for each gene and tissue type represents the maximum nTPM value between the HPA and GTEx datasets [1]. When a tissue contains multiple sub-tissues (specifically brain regions, immune cells, lymphoid tissues, and intestine), the maximum value across all sub-tissues is taken for that tissue type [2].

Sources:
[1] "The consensus nTPM value for each gene and tissue type represents the maximum nTPM value based on HPA and GTEx." — The human proteome - Methods summary - The Human Protein Atlas (https://www.proteinatlas.org/humanproteome/tissue/method/transcriptomics)
[2] "For tissues with multiple sub-tissues (brain regions, immune cells, lymphoid tissues and intestine) the maximum of all sub-tissues is used for the tissue type and the total number of tissue types in the human tissue consensus set is 37." — The human proteome - Methods summary - The Human Protein Atlas (https://www.proteinatlas.org/humanproteome/tissue/method/transcriptomics)
