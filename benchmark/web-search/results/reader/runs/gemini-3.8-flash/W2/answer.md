**Q:** Which Ensembl version does the current Human Protein Atlas release build on?

The current Human Protein Atlas release (version 25.1) builds on Ensembl version 109 [1].

Sources:
[1] "The XML file contains most of the data in the Human Protein Atlas version 25.1, including protein expression data (in normal and tumor tissues and in cell lines), antigen sequences, Western blot data for antibodies, protein array data for antibodies, RNA-seq data, external references such as UniProt identifiers, and more. The data is based on Ensembl version 109." — Downloadable data - The Human Protein Atlas (https://www.proteinatlas.org/about/download)
