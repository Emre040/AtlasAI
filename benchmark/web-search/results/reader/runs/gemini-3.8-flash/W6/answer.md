**Q:** What kind of data did release 25.1 add to the Single Cell resource, and across how many cell types and how many tissues?

Protein Atlas release 25.1 added Deep Visual Proteomics (DVP) data, consisting of cell-type resolved mass spectrometry-based protein profiles, to the Single Cell resource [1]. These data cover 27 different cell types (grouped into 24 cell types for classifications) across 14 different tissues [1].
