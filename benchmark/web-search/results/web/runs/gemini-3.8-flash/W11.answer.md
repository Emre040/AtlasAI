# W11 (documentation)

**Q:** How is the consensus nTPM value of a gene in a tissue derived from the HPA and GTEx transcriptomics data?

**gemini-3.8-flash:**

According to the Human Protein Atlas (HPA) [Methods summary on transcriptomics](https://www.proteinatlas.org/humanproteome/tissue/method/transcriptomics), the consensus normalized transcript expression (nTPM) value of a gene in a tissue is derived through the following steps:

1. **TPM Calculation and Scaling (pTPM):** 
   - For both the HPA and GTEx datasets, the average TPM (transcripts per million) value across all individual samples for each tissue type is used to estimate gene expression.
   - TPM values per sample are scaled to sum to 1 million TPM (designated **pTPM**) to compensate for previously removed non-coding transcripts.

2. **Cross-Sample Normalization (nTPM):** 
   - All sample TPM values within each data source are normalized separately using the **Trimmed Mean of M values (TMM)** method to enable comparisons between samples, yielding **nTPM** values for each gene.

3. **Consensus Determination:**
   - For a given gene and tissue type, the **consensus nTPM** is taken as the **maximum nTPM value** between the HPA and GTEx datasets.
   - For tissues comprising multiple sub-tissues (such as brain regions, lymphoid tissues, immune cells, and intestine), the **maximum value across all sub-tissues** is selected for that tissue type.
