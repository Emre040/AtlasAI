Single cell type methods

This part of the Single cell resource contains Single cell type information based on single cell RNA sequencing (scRNA-seq) and single nuclei RNA sequencing (snRNA-seq) data from 34 human tissue types, including blood. The data is linked to in-house generated immunohistochemically stained tissue sections presented in the Tissue [4] resource in order to visualize the corresponding spatial protein expression patterns. The single cell analysis is based on publicly available genome-wide expression data [39] and comprises all protein-coding genes in 1175 individual cell type clusters corresponding to 15 different cell type classes, and 154 different cell types, this data is also summarised into 53 for classfication and overview. A specificity classification was performed to determine the number of genes elevated in the single cell types, as well as grouped cell types. The genes expressed in each of the cell types can be explored in interactive UMAP plots and bar charts, with links to corresponding immunohistochemical stainings in human tissues.

More information about the specific content, the generation and analysis of the data can be found on the Methods Summary [40]. A cluster comparison between the HPA pipeline and the Tabula Sapiens can be found here [41].

THE SINGLE CELL TYPE PROTEOMES i

Explore the proteomes of the single cell types in the pages below. Each page is dedicated to a cell type class and each class includes cell type groups with functional features in common. Symbols and names are clickable and will redirect to the corresponding page. If you hover the mouse-pointer over a certain symbol or name, the corresponding location in the human body will be highlighted in the human figures.

The tree-like cell type dendrogram below shows the relationship between the grouped single cell types based on genome-wide expression. The color-coding corresponds to the cell type class presented above. Each cell type name is clickable and will redirect to the corresponding section of the cell type proteomes. If you hover the mouse-pointer over a certain symbol or name, the corresponding location in the human body will be highlighted in the human figures.

The cell type dendrogram is based on agglomerative clustering of 1 - Spearman's rho between cell types using Ward's criterion. The dendrogram was then transformed into a hierarchical graph, thus where link distances were normalized to emphasize graph connections rather than link distances. Link width is proportional to the distance from the root, and are colored according to cell type group if only one cell type class is present among connected leaves.

SINGLE CELL TYPE EXPRESSION i

The UMAP was generated by clustering genes based on expression patterns. The colored areas represent the area in the UMAP where most of the genes of each cluster reside. Click on a cluster or Go to interactive expression cluster page [57] to view an interactive UMAP and details about all cluster annotations.

The RNA data was used to cluster genes according to their expression across single cell types. The clustering of 19294 genes showing expression above cut of in the in single cell types resulted in 110 expression clusters, which have been manually annotated to describe common features in terms of function and specificity. The result of the cluster analysis is presented as a UMAP based on gene expression, where each cluster has been summarized as colored areas containing most of the cluster genes.

Go to interactive expression cluster page [57]
