# W20 (documentation)

**Q:** Why does the Human Protein Atlas not provide its human tissue RNA-seq data in raw format?

**gemini-3.8-flash:**

According to the Human Protein Atlas Help and FAQ page, human tissue RNA-seq data is not provided in raw format due to **GDPR legislation** (General Data Protection Regulation). 

Instead, the resource provides processed expression values (such as TPM tables) on its download page. They note that they are working on making raw RNA-seq data available through a secure federated European Genome-phenome Archive (EGA) repository where access can be managed, though timelines for this remain uncertain.

**Source URL:**
- [Human Protein Atlas – Help & FAQ](https://www.proteinatlas.org/about/help)
