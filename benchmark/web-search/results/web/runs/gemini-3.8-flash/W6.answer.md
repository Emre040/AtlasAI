# W6 (documentation)

**Q:** What kind of data did release 25.1 add to the Single Cell resource, and across how many cell types and how many tissues?

**gemini-3.8-flash:**

According to the Human Protein Atlas release notes for version 25.1 (available at [Human Protein Atlas Release History](https://www.proteinatlas.org/about/releases)):

* **Kind of data added:** Release 25.1 added **Deep Visual Proteomics (DVP)** data, consisting of cell-type resolved, mass spectrometry (MS)-based protein profiles.
* **Number of cell types:** The data covers **27 different cell types** (specifically, 27 cell type shapes with 3–5 replicates each, grouped into 24 cell types used for classifications).
* **Number of tissues:** The profiles represent **14 different tissues**.
